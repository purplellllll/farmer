# S6E7 2nd-place writeup：对 Farmer 的可迁移启发

原方案是一个三分类表格集成：18 个基模型先生成 OOF 概率，使用按类别的非负权重做
线性融合，再用按类别的概率乘子直接优化 balanced accuracy。它最重要的经验不是某个
具体分类器，而是把模型选择、组合和最终指标校准拆开，并完全依赖可复现的 OOF 证据。

对 Farmer 的对应关系如下：

| S6E7 做法 | Farmer 中的对应实现 |
|---|---|
| 共享 OOF 预测 | 固定 seeds、交换座位、完整 720-step 的独立 holdout 对局 |
| 18 个互补基模型 | starter、GPU/CPU 不同 seed checkpoint、规则策略和集成策略 |
| 单纯形约束线性融合 | 对各策略的合法动作概率做非负加权并重新归一化 |
| class-specific multiplier | 按动作族校准 PASS、移动、种植、照料、收获和市场动作概率 |
| 不追逐 Public LB | 不按单轮 self-play 胜率或少量 Kaggle 提交分数选权重 |

当前 GPU v5 不应因为这个 writeup 立即中断。它的 PPO 更新已经数值稳定，下一步应先为
多个 checkpoint 保存同一 holdout 上的逐步合法动作概率和完整对局结果，再只在训练 seeds
之外优化策略权重与动作族乘子。线性混合必须经过新的外层 seeds 验证；否则它会像在同一
份 OOF 上反复调 stacking 一样过拟合。

特别值得借鉴的是不平衡校准。当前策略的主要不平衡不是标签类别，而是安全的 PASS/移动
动作远多于决定长期收益的种植、照料、收获和市场动作。后续可以在不破坏合法动作 mask 的
前提下，为这些动作族学习正乘子；最终仍需重新归一化，并以完整游戏胜率而非动作准确率
选择乘子。
